# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, by reference. The full text at that link is the standard we hold ourselves and each other to.

## Scope

It applies in every space that belongs to the project: the issue tracker, pull requests, discussions and review comments. It also applies when someone represents the project in public.

## Reporting

Please do not report conduct concerns in a public issue or pull request.

Use GitHub's private vulnerability reporting on this repository (the "Security" tab, then "Report a vulnerability"), the private channel described in [SECURITY.md](SECURITY.md). Start the report with "Conduct report" so a maintainer can route it. If that is unavailable, follow the fallback in SECURITY.md.

That channel was built for security reports, and there is no dedicated conduct contact yet. Reports sent there go to the maintainer, who is responsible for enforcement.

## Enforcement

Maintainers follow the enforcement guidelines in the Contributor Covenant 2.1 text linked above when they respond to a report. They keep the reporter's identity private.
