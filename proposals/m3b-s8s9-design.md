**3. Architecture to freeze in the briefs**

Doctor should be a pure `doctorReport(input: DoctorInput): { lines: string[]; exitCode: 0 | 1 | 2 }`. Its input is constructed by the CLI from public gateway metadata calls and reviewed build metadata. Suggested closed field groups:

```ts
type DoctorInput = Readonly<{
  release: { name: string; version: string; schema: '0.2' };
  runtime: { node: string; platform: string; arch: string;
    lossless: 'ok' | 'unsupported'; verification: 'recorded' | 'unverified' };
  source: { alias: string; loopback: 'literal-ok' | 'invalid';
    auth: 'none' | 'client_credentials'; classification: 'operator-declared-synthetic' };
  metadata: { status: 'ready' | 'unavailable' | 'invalid';
    fhir: '4.0.1' | 'other' | 'unknown'; capabilityRevision?: string;
    summary: 'complete' | 'partial' | 'unknown' };
  workflow: { id: 'recent-labs-v1'; patient: 'ready' | 'not-ready';
    observation: 'ready' | 'not-ready';
    searchProfile: 'generic-r4' | 'synthetic-fixture-r4-v1' | 'hapi-r4-labs-v1';
    proof: 'qualified' | 'unproved' };
  output: { format: 'fhir'; delivery: 'full-text-v1' | 'structured-evidence-v1';
    defaultBytes: number; maxBytes: number; ttlMs: number; retentionBytes: number };
  artifacts: { schemaSha256: string; parametersSha256: string; supportSha256: string };
  patientIdentifierSystemCount: number;
  proxyRisk: 'present' | 'absent';
  faults: readonly DoctorFaultCode[];
}>;
```

This is a field proposal, not a claim that the formatter can accept arbitrary strings. Freeze finite release/profile enums from the completed registries; runtime/platform/version/hash/alias/numeric fields have bounded lexical validators; reject unknown DTO keys and nested extras. Fault codes are a finite union, never `Error.message`. No patient ID/context handle, raw configuration, source software string, URL/path, resource, secret or arbitrary prose reaches the formatter. Runtime admission failures and invalid config/profile/DTO yield 2; unavailable or unsupported workflow/FHIR yields 1; all required checks ready yields 0. Unproved search semantics are displayed as limitations, not automatically a broken generic workflow. “Synthetic” is operator classification, not a data-classifier result.
