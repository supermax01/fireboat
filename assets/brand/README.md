# fireboat brand assets

| File | Use |
| --- | --- |
| `icon.svg` | Square mark (512 viewBox). Use this wherever possible. |
| `icon-16.png` … `icon-512.png` | Raster exports of the mark. |
| `wordmark.svg`, `wordmark-dark.svg` | Mark plus lowercase "fireboat" for light and dark backgrounds. "fire" is set in the warm accent. |
| `wordmark-proof.png`, `wordmark-dark-proof.png` | Rendered proofs of the wordmarks. |

**Concept: "angular sail".** A straight triangular sail split into Ember and Amber halves rises above a broad Chalk hull on an Ink tile.

**Palette:**

| Name | Hex |
| --- | --- |
| Ember | `#D84A2B` |
| Amber | `#FFB547` |
| Ink | `#202936` |
| Chalk | `#FFF4E8` |

The warm palette is inspired by the HL7 FHIR logo. The mark is deliberately distinct from it: it uses flat document and hull geometry, with no flame silhouette and no official lettering. Always write the name in lowercase: `fireboat`.

The design was produced by GPT-6.1-Sol in a delegated design task. The generated concepts, the name screen and the earlier drafts are kept outside the repository.
