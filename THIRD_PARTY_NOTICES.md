Regenerate with `python3 scripts/generate-r4-index.py --download`. The script verifies the source hash and only reads StructureDefinition JSON; it does not execute package code.

`packages/core/src/generated/r4-search-parameters.json` is a derived SearchParameter typing catalog from the same **HL7 FHIR R4 core 4.0.1** package and hash. Descriptions in the catalog are reproduced verbatim from HL7 (CC0). Regenerate with `python3 scripts/generate-r4-search-parameters.py`. Regeneration requires the pinned archive at `.local/` (obtain it with `generate-r4-index.py --download`); the search-parameter generator has no download step of its own. The script reads only SearchParameter JSON, excludes the three example-named members, and executes no package code or search expressions. Canonical definition URLs in the catalog are identifiers only; the gateway never fetches them.

The synthetic quickstart seed contains LOINC®, UCUM, HL7® Terminology (THO) and BCP 47 codes and records generated with Synthea™; the test and eval fixtures also contain LOINC and UCUM codes. Their notices, including the notice that section 10.1 of the LOINC licence requires, are in [licenses/SEED_NOTICES.md](licenses/SEED_NOTICES.md), which ships in this package. The repository's data contains no SNOMED CT codes or descriptions. Only HL7 specification metadata in the generated R4 index mentions that terminology.

The npm dependencies that ship with the gateway are `@modelcontextprotocol/server` and `@modelcontextprotocol/core` (Apache-2.0) and `zod` (MIT). The quickstart helper adds further npm packages. Their licence texts are copied verbatim under [licenses/dependencies/](licenses/dependencies/) and listed in [licenses/inventory.json](licenses/inventory.json). No formal rights review of the seed data beyond the sources cited in [licenses/SEED_NOTICES.md](licenses/SEED_NOTICES.md) has been completed, so the inventory records `pending-owner-review` for the seed generator and for every coding system.
